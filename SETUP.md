# GenAI ITS Local Setup Guide

## Purpose

This guide explains how to set up and run the GenAI ITS project locally for development. It supports the Deployment & Infrastructure workstream by documenting local installation, environment configuration, Firebase secrets setup, and common setup issues.

## Project Stack

- Python
- Streamlit
- Groq API
- Firebase / Firestore
- LangChain
- FAISS
- Unstructured PDF processing
